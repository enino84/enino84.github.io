# Experience

My work runs on two tracks that feed each other. In research I build ensemble-based data assimilation methods that correct numerical forecasts using noisy observations. In industry I work as a consultant in data engineering, data science and applied AI, delivering production data platforms, forecasting models, and LLM and agent systems.

For the industry side, see **[details and full experience](/consulting)**.
